База данных автосервиса

Описание проекта

Необходимо разработать простую базу данных для автосервиса. База данных должна хранить информацию о владельцах автомобилей, автомобилях, мастерах и проведённых ремонтах.

  • Владельцы — клиенты автосервиса;
  • Машины — автомобили клиентов;
  • Мастера — сотрудники автосервиса;
  • Ремонты — информация о выполненных ремонтах.

1. Таблица «Владельцы»

Хранит информацию о владельцах автомобилей.

Связи между таблицами

Владелец → Машины
Один владелец может иметь несколько автомобилей. Связь: 1 : N
Машина → Ремонты
Один автомобиль может проходить ремонт несколько раз. Связь: 1 : N
Мастер → Ремонты
Один мастер может выполнить много ремонтов. Связь: 1 : N

Создание таблиц в SQLite

SQL-код ниже можно целиком выполнить в SQLite. Отступы сделаны так, чтобы структура каждой таблицы была хорошо видна.

PRAGMA foreign_keys = ON;

CREATE TABLE owners (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    phone TEXT,
    address TEXT
);

CREATE TABLE cars (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    brand TEXT NOT NULL,
    model TEXT NOT NULL,
    year INTEGER,
    plate_number TEXT,
    owner_id INTEGER NOT NULL,

    FOREIGN KEY (owner_id)
        REFERENCES owners(id)
);

CREATE TABLE masters (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    phone TEXT,
    specialization TEXT
);

CREATE TABLE repairs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    car_id INTEGER NOT NULL,
    master_id INTEGER NOT NULL,
    description TEXT NOT NULL,
    repair_date TEXT,
    price REAL,

    FOREIGN KEY (car_id)
        REFERENCES cars(id),

    FOREIGN KEY (master_id)
        REFERENCES masters(id)
);

Что нужно запомнить

  • PRIMARY KEY — уникальный идентификатор записи.
  • FOREIGN KEY — связь с другой таблицей.
  • NOT NULL — поле обязательно для заполнения.
  • INTEGER — целое число.
  • TEXT — текст.
  • REAL — число с дробной частью.
